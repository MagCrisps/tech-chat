## 一、什么是任务分解（Task Decomposition）

任务分解是指把一个复杂、模糊的大目标，拆解成若干**粒度合适、可独立执行、可验证**的小任务的过程。
它是规划（Planning）能力的核心，也是 Agent、项目管理、软件工程中的通用方法。

### 1.1 为什么需要任务分解

- **降低复杂度**：单个小任务的上下文更短，模型出错的概率更低。
- **可并行**：相互独立的任务可以并行执行，缩短整体耗时。
- **可验证**：每个子任务都有明确的完成标准，便于逐项验收与回滚。
- **可复用**：常见子任务（检索、总结、校验）可以沉淀为固定工具或模板。

### 1.2 常见分解策略

1. **自顶向下拆分（Top-Down）**：按目标的层级结构拆分，例如「发布一个服务」拆为
   需求 → 设计 → 编码 → 测试 → 上线。
2. **按阶段拆分（Workflow）**：把流程拆成有先后依赖的步骤链，适合流程固定的场景。
3. **按角色/模块拆分（Divide and Conquer）**：按职责边界拆分，例如前端 / 后端 / 数据。
4. **迭代式拆分（Iterative / ReAct）**：先只拆出下一步，执行后根据结果再决定下一步，
   适合不确定性高的探索型任务。

### 1.3 好的子任务标准（验收清单）

- 单一职责：一个子任务只做一件事。
- 输入输出明确：知道自己需要什么、要产出什么。
- 可独立验证：有客观的完成判据，而不是「感觉做完了」。
- 粒度适中：一般单个子任务的工作量在「几分钟到几小时」之间比较合适。

### 1.4 一个例子

目标：**为团队搭建一个内部技术问答机器人**

```text
1. 明确需求与数据范围        -> 输出：需求说明 + 数据来源清单
2. 收集并清洗技术文档        -> 输出：data/ 目录下的 md / pdf 文件
3. 搭建向量检索（RAG）       -> 输出：可查询的 Chroma 向量库
4. 编排对话流程（Agent）     -> 输出：可多轮对话的图（StateGraph）
5. 提供 Web 界面与流式输出   -> 输出：可访问的页面
6. 评测与迭代               -> 输出：评测集 + 优化结论
```

## 二、RAG（检索增强生成）基础

RAG = Retrieval-Augmented Generation，即「先检索、再生成」。

### 2.1 核心流程

1. **索引（Indexing）**：加载文档 → 切分（chunk）→ 向量化 → 写入向量库。
2. **检索（Retrieval）**：把用户问题向量化，在向量库中做相似度搜索，取回 Top-K 片段。
3. **生成（Generation）**：把检索到的原文片段作为上下文交给大模型，让模型基于原文作答。

### 2.2 关键参数

- `chunk_size`：单个文本块的长度，太大噪声多，太小语义不完整。常用 500 ~ 1000。
- `chunk_overlap`：相邻块的重叠长度，避免句子被硬切断。常用 chunk_size 的 10% ~ 20%。
- `top_k`：检索返回的片段数量，常用 3 ~ 5。
- `add_start_index`：记录每个块在原文中的起始偏移，用于回答时标注来源。

### 2.3 常见问题与规避

| 问题 | 表现 | 规避方式 |
| --- | --- | --- |
| 幻觉 | 答案里出现原文没有的说法 | 在系统提示中要求「只依据原文作答，缺失就明确说明未找到」 |
| 检索不到 | 明明有文档却答「未找到」 | 换更适合中文的 embedding 模型；调小 chunk_size；增加 top_k |
| 重复入库 | 重启后向量条数翻倍 | 用文件指纹（大小 + mtime）做增量判断，重新索引前先按来源删除旧向量 |
| 答非所问 | 检索到不相关片段 | 在提问时保留技术名词；必要时先让模型改写查询 |

## 三、LangGraph 中的 Agentic RAG

传统 RAG 是「每次都检索」，Agentic RAG 让模型自己决定**是否需要检索**：

- 用 `@tool` 定义 `retrieve(query)`，并在 docstring 里写清「何时该用 / 何时不该用」。
- 用 `llm.bind_tools([retrieve])` 绑定工具。
- 用 `tools_condition` 做条件路由：模型产生 `tool_calls` 就走检索节点，否则直接回答。
- 用 `MemorySaver` + `thread_id` 保存多轮对话状态，实现上下文记忆。

这样一来，问「你好」不会触发检索，问「什么是任务分解」则会触发检索并给出带来源的答案。
